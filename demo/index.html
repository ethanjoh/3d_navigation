3D Model Space

Three.js WebGL 기술을 사용하여 각 폴더 내에 배치된 GLB 3D 입체 모델을 실시간으로 로드하고 자유롭게 제어해 보세요.

💡 본 데모는 기존의 WRL(VRML) 파일을 Blender에서 Import한 후 GLB 포맷으로 변환하여, 웹 브라우저에서 별도의 뷰어 확장 프로그램(Plugin) 설치 없이도 즉시 감상할 수 있도록 제작되었습니다.

⚙️

Drill Machine

드릴 머신 부품 및 외관 기하학적 형태의 3D 모델입니다. 정밀한 조립 구조와 세부 메커니즘을 3D 뷰포트에서 확인하세요.

drill-exam / drill.glb

NC Machine

수치제어(NC) 공작기계 장비의 3D 모델입니다. 대형 기계 설비의 형태와 구조적 레이아웃을 다각도로 탐색할 수 있습니다.

nc_exam / nc.glb

Robot Pendant

산업용 로봇 펜던트 장비의 3D 모델입니다. 하드웨어 바디 및 관절 구동 파트의 구조를 가상 공간 내에서 직접 제어합니다.

robot_exam / robot.glb
